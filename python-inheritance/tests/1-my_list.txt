1-my_list module

MyList inherits from list

print_sorted prints the list in ascending order

importing the module:

>>> MyList = __import__('1-my_list').MyList

function use through Class:

>>> my_list = MyList()
>>> my_list.append(1)
>>> my_list.append(4)
>>> my_list.append(2)
>>> my_list.append(3)
>>> my_list.append(5)
>>> print(my_list)
[1, 4, 2, 3, 5]
>>> my_list.print_sorted()
[1, 2, 3, 4, 5]

expected errors based on given condtions:

all elements of list must be integers

>>> my_list = MyList()
>>> my_list.append(1)
>>> my_list.append(3.1)
>>> my_list.append(2)
>>> my_list.append(3)
>>> my_list.append(5)
>>> print(my_list)
[1, 3.1, 2, 3, 5]
>>> my_list.print_sorted()
[1, 2, 3, 3.1, 5]

when list is empty

>>> my_list = MyList()
>>> my_list.print_sorted()
[]
